# 台指期跨月價差進場決策工具（吃正二轉倉豆腐）

純前端靜態網頁＋PWA 決策輔助工具，幫你判斷現在適不適合進場做台指期跨月價差（買進價差單：賣近月＋買遠月）。開啟即可計算理論價差、安全邊際與結算／籌碼風險，給出 🟢／🟡／🔴 燈號，手機與電腦皆可使用。

## 線上使用（GitHub Pages）

- 線上網址（需先於 Repo Settings → Pages 啟用 `main` 分支 `/ (root)`）：  
  `https://pilimesai.github.io/tx-calendar-spread-tool/`
- 支援手機響應式版面與 PWA（iOS Safari「分享 → 加入主畫面」或 Android Chrome「加到主畫面」可當作 App 使用）。

## 功能
- **理論跨月價差與 MA10 雙軌判斷**：`理論價 = 指數 × 年利率 × 結算間隔天數 / 365 − 區間預計除息點數`，並對照**近 10 日均價差（MA10）**辨識「價值折價買點」、「回檔買點」或「短線過熱追高」
- **多空籌碼拔河與投信 20 日趨勢**：比較**投信淨多單（正二及高息 ETF 主力）÷ 外資淨空單**比值與淨差，並自動追蹤投信淨多單較 20 個交易日前的增減（「豆腐變肥」vs「豆腐縮水」）；當投信縮水時維持基本部位並暫停 2 倍加碼
- **大盤急殺風控、崩盤月鎖定與除權降口**：自動抓加權指數近 5 日漲跌幅序列，急跌逾 **3%** 降黃燈警戒、跌逾 **5%** 亮紅燈，且結算週（`T-5` 起）內曾跌逾 5% 即自動鎖定本月停手；並於 **6～7 月／預計除息 ≥ 150 點高峰** 自動建議口數減半或降規格
- **超值加碼與虛擬第六檔階梯預掛停利**：綠燈且報價壓回 **≤ min(理論價, MA10)**（且投信未縮水）時提醒放大 2 倍口數（除權高峰仍維持減半上限，如 1→2 口）；並善用期交所價差 ROD 限價單「最佳衍生一檔（虛擬第六檔）」撮合優先權，自動算出**階梯預掛停利價（第 1 批 `+40`／第 2 批 `+65`）**
- **視覺化價差溫度計與六大風控體檢**：將價位安全邊際、結算時機（含 13:15 尾盤黑洞）、大盤急殺風控、多空籌碼力道、五檔流動性與除權息變數排序呈現
- **損益試算**：支援 TX（200 元/點）、MTX（50 元/點）、TMF（10 元/點），算出階梯預估損益、洗盤緩衝資金與除權高峰減半口數預估
- **盤後資料自動更新**：由 GitHub Actions（`.github/workflows/update_data.yml`）於每個交易日台灣時間 15:35、17:35、19:35 執行 `fetch_data.py` 更新 `data/market.json`，自動抓取期交所台指期近遠月結算價、近 10 日均價差（MA10）、投信淨多單（含近 20 日增減趨勢）／外資淨空單、銀行公會 TAIBOR 1 個月期短期利率、加權指數近 5 日漲跌幅（FMTQIK），並結合證交所除權息預告表（TWT48U）與上市發行股數（t187ap03_L）、每日收盤（STOCK_DAY_ALL）自動精算帶入區間已公告除息蒸發點數
- **⚡ 盤中即時報價（Cloudflare Worker）**：可搭配 `worker/taifex-proxy.js` 轉發期交所 `mis.taifex.com.tw` 即時複式單報價，在手機上每 15 秒自動同步跨月價差、近月點位與五檔買賣價差

## ⚡ 盤中即時報價設定（Cloudflare Worker）

1. 依 [worker/README.md](worker/README.md) 將 [worker/taifex-proxy.js](worker/taifex-proxy.js) 部署到免費 Cloudflare Worker（可網頁貼上或執行 `npx wrangler deploy`）。
2. 在決策網頁的「⚡ 盤中即時報價」點 **⚙️ 設定 API**，貼入你的 `https://tx-spread-live-proxy.<你的帳號>.workers.dev` 網址後按 **儲存並抓取**。
3. 小技巧：也可以直接把 `?api=https://你的worker網址` 加在網頁網址後面存成手機書籤，打開即自動記憶並同步。

## 本機預覽與手動更新資料

不需安裝額外套件，直接使用 Python 內建伺服器即可預覽（請勿直接用 `file://` 開啟，否則無法讀取 `data/market.json`）：

```bash
python -m http.server 8765
```

開啟 `http://127.0.0.1:8765`。

若需手動更新最新盤後資料：

```bash
python fetch_data.py
```

## 注意事項
- 結算日預設以「每月第三個週三」推算，遇到國定假日順延請在介面上手動覆寫結算日
- 外資未平倉淨空單僅有盤後資料，盤中即時模式會自動沿用最新盤後的外資淨空單水位
- 除息蒸發點數已自動依證交所已公告之成份股除息與股數市值精算帶入（自動排除 ETF／REITs）；每年 6～7 月除息旺季若有大型權值股尚未公告日期，可於「進階設定」取消勾選「除息日均已公告」
- 這個工具只是輔助判斷，不構成投資建議
